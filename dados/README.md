# Dataset fictício

`vendas.csv` contém registros sintéticos reproduzíveis de pedidos entre 2024 e 2025. Cada linha é um item de pedido, com data, identificadores fictícios, segmento, categoria, produto, quantidade, preço, desconto e receita. Nenhuma informação representa pessoas reais. Para regenerar: `python backend/generate_data.py`.
